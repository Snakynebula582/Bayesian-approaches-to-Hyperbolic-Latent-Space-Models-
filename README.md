The contents of this repository contain the code I used in my undergraduate degree final thesis. In particular they are a collection of Hyperbolic Latent Space models 
that are estimated via Bayesian means. To run these models, first source the "All Helpers.R" file which contains all the helpers for all the models, then source the "All Models.R"
file to load in the estimation blocks. The "Examples.R" file contains instructions on how to call each of these models and has a placeholder random graph to showcase them.
